# Qynl Agent V15

V15 is a major **runtime reliability and control update**. V14 added tasks, evaluation and skill memory. V15 makes the pieces cooperate through a shared blackboard and adds an independent runtime watchdog plus explicit action verification.

## Architecture

## Shared blackboard

`minecraft/v15_blackboard.py` provides a bounded shared state object for the agent loop.

It tracks:

- current goal
- active subtask
- success hint
- current temporal state
- latest state delta
- last action
- last evaluation
- strategy mode
- recent failures
- recent events

This avoids different layers independently keeping conflicting versions of the agent's current situation.

The event and failure histories are bounded.

## Runtime watchdog

`minecraft/v15_watchdog.py` adds an independent runtime budget layer.

It can reject:

- actions longer than the configured maximum
- new actions after too many consecutive failures
- steps that exceed the time budget

The watchdog is not controlled by the model.

## Action verification

`minecraft/v15_action_verifier.py` compares pre/post temporal states and records whether an observable change occurred.

It considers:

- overall state change
- entity changes
- landmark changes
- hazard changes
- UI changes

This remains an **observable-change signal**, not proof that the overall Minecraft goal succeeded. V14's separate goal evaluator remains responsible for subtask success.

## Why V15 matters

V14 had many useful components, but a complex agent needs a consistent control center. V15 makes the flow explicit:

```text
Perception → shared state → planning → bounded action → verification → evaluation → memory
```

The watchdog adds another important distinction:

```text
Model decides WHAT might help
Runtime decides WHETHER it is safe to execute
```

## Safety chain

```text
Model output
    ↓
Strict Minecraft parser
    ↓
Runtime Watchdog
    ↓
ActionPolicy
    ↓
Force ESC
    ↓
Minecraft executor
```

No shell, OS command execution, arbitrary desktop automation, credentials or unrestricted computer control are introduced.

## Tests

V15 adds tests for:

- bounded blackboard history
- action duration limits
- action verification

## Limitations

V15 improves runtime reliability and coordination. It does not make perception infallible or turn observable screen changes into guaranteed task success. The actual Minecraft skill remains dependent on the selected models and environment.
