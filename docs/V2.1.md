# Qynl Agent V2.1

V2.1 is a quality and reliability release built on the V50 architecture. It deliberately avoids another architectural rewrite.

## Goals

- reduce noisy perception decisions
- make action outcomes explicit
- improve feedback available to replanning
- add regression coverage without changing the core architecture

## Observation smoothing

`minecraft/v21_observation_smoother.py` maintains a small bounded window of recent observations and produces a confidence estimate. This is intentionally lightweight: it reduces confidence jitter but does not pretend that averaging observations solves visual perception.

## Verified action feedback

`minecraft/v21_action_feedback.py` defines SUCCESS, PARTIAL, FAILED and UNKNOWN outcomes. UNKNOWN is not considered verified. Progress deltas are bounded to `[-1, 1]`.

## Tests

`evals/test_v21.py` adds coverage for confidence clamping, bounded observation history, feedback validation and unknown-result handling.

## Versioning

V50 remains the major architecture milestone. V2.1 is a product/versioning reset, not a replacement of the V50 internals.

```text
V2.0  = V50 architecture baseline
V2.1  = reliability + quality
V2.2  = incremental improvements
...
V3.0  = only when another genuinely major architectural change is justified
```
