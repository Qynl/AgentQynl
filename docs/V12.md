# Qynl Agent V12

V12 improves the V11 closed loop with a richer state tracker and a strategy layer that reacts to confidence, repeated states and repeated actions.

## Core loop

```text
Minecraft
  ↓
Vision
  ↓
GameState
  ↓
Goal + Strategy
  ↓
Planner
  ↓
MinecraftAction
  ↓
Policy + Force ESC
  ↓
Minecraft
  ↓
Vision again
  ↓
Transition / progress score
  ↓
Memory + strategy update
  ↓
next action
```

## State tracking

`minecraft/v12_state.py` turns visual analysis into a normalized `GameState` containing:

- summary
- landmarks
- hazards
- visible UI
- confidence

The tracker keeps bounded state and transition history. A transition records whether the state changed and a novelty heuristic based on visible tokens.

The progress score is deliberately only a heuristic. Visual change does not automatically mean that a Minecraft goal succeeded.

## Strategy controller

`minecraft/v12_strategy.py` adds lightweight adaptive behavior:

- **cautious** when model confidence is low
- **explore** when the visual state repeats
- **vary** when the same action is repeated too often
- **normal** when the loop is making useful progress

This strategy layer does not execute actions. It changes the planning context/instruction; the normal parser, ActionPolicy and Force ESC still control execution.

## Why this improves V11

V11 knew whether the visual state changed, but treated many different kinds of change similarly. V12 retains the history and explicitly tracks:

```text
state → action → state → novelty
```

That gives the planner useful signals for avoiding loops and for being more cautious when perception is uncertain.

## Safety

V12 does not expand computer permissions. It remains Minecraft-only and keeps the existing deny-by-default ActionPolicy, bounded actions and independent Force ESC.

No automatic model-weight updates are performed.

## Tests

`evals/test_v12.py` covers transition scoring and strategy behavior for low confidence and repeated actions.
