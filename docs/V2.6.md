# Qynl Agent V2.6

V2.6 is the navigation-focused release. It adds a bounded pathfinding layer while keeping V50's safety and execution boundaries intact.

## Added

- `minecraft/v26_pathfinding.py`: bounded A* search over a discrete 3D grid
- `minecraft/v26_navigation.py`: converts a planned path into the next navigation step
- `minecraft/v26_stuck_detector.py`: detects repeated no-progress observations
- `minecraft/v26_path_cost.py`: path length/risk scoring for planner selection
- expanded `evals/test_v26.py`

## Pathfinding flow

```text
WORLD / OBSERVATION
        ↓
KNOWN BLOCKED CELLS
        ↓
A* PATHFINDER
        ↓
PATH + EXPANSION LIMIT
        ↓
PATH COST / RISK
        ↓
NEXT NAVIGATION STEP
        ↓
EXECUTE THROUGH EXISTING SAFETY LAYERS
        ↓
VERIFY MOVEMENT
        ↓
STUCK DETECTOR
        ↓
REPLAN / RECOVER
```

## Important boundary

The V2.6 pathfinder is a planning primitive, not a complete Minecraft movement controller. A real Minecraft navigation system still needs environment-specific collision, terrain, jumping, falling, doors, fluids, ladders, path invalidation and fresh world observations.

The expansion limit is deliberate: a path request cannot consume unbounded compute.

## Versioning

```text
V2.0 = V50 architecture baseline
V2.1 = observation + action-feedback reliability
V2.2 = debugability + progress measurement + pacing
V2.5 = navigation/recovery foundations
V2.6 = bounded pathfinding + navigation feedback
V3.0 = only for a genuinely major architecture change
```
