# Qynl Agent V21

V21 is the **prediction + exploration update**. V20 gave Qynl a persistent world model and candidate-based planning. V21 adds a decision layer for uncertainty: when the agent does not know enough, it can deliberately gather information instead of pretending certainty.

## V21 architecture

```text
Minecraft screen
      ↓
Vision
      ↓
World Model + Spatial Memory
      ↓
Goal + Skill Memory
      ↓
Candidate Planner
      ↓
Transition Predictor
      ↓
V21 Controller
   ┌──┼─────────────┐
 goal  explore   safe-stop
  ↓      ↓           ↓
rank   reobserve   no action
  ↓    look around
  ↓    small scan
  ↓      ↓
Safety pipeline
      ↓
Force ESC
      ↓
Minecraft
      ↓
Verify
      ↓
World Model
```

## Spatial memory

`minecraft/v21_spatial_memory.py` keeps bounded relative landmark observations. It can detect repeated observations of landmarks and expose recent spatial context.

It intentionally stores coarse relations rather than pretending screen-only perception provides exact world coordinates.

## Information-gain exploration

`minecraft/v21_exploration.py` provides conservative exploration decisions.

Examples:

- low confidence → `reobserve`
- repeated state → `look_around`
- insufficient evidence in an unknown area → `small_scan`
- hazard → `retreat_or_stop`

This creates an explicit distinction between **acting toward the goal** and **gathering information needed to act toward the goal**.

## Transition prediction

`minecraft/v21_predictor.py` estimates expected progress, uncertainty and risk for already-generated candidates.

The predictor is deliberately lightweight. It is a ranking signal, not a claim that Qynl has a perfect simulator of Minecraft physics.

## Decision controller

`minecraft/v21_controller.py` combines the signals:

```text
Enough information + safe → choose predicted action
Low confidence / repeated / unknown → explore
Danger → safe stop
No viable candidate → replan
```

The controller does not execute actions directly. Chosen actions still pass through the existing parser, rate limiter, watchdog, ActionPolicy and Force ESC path.

## V20 → V21

V20 answered:

```text
What is around me?
Which actions could advance the goal?
```

V21 adds:

```text
How sure am I?
Would observing more be better than acting?
What outcome do I expect from each candidate?
What is the risk?
```

That enables a more useful loop:

```text
Observe → Model → Predict →
Act OR Explore → Verify → Update
```

## Safety

V21 does not add shell access, arbitrary OS control, credentials or unrestricted desktop automation.

```text
Model
 ↓
Strict Minecraft action representation
 ↓
Rate Limiter
 ↓
Runtime Watchdog
 ↓
ActionPolicy
 ↓
Force ESC
 ↓
Minecraft executor
```

The predictor and exploration layer cannot bypass the execution gates.

## Tests

`evals/test_v21.py` covers:

- spatial landmark revisitation
- uncertainty-driven exploration
- risk-aware candidate prediction
- hazard safe-stop

## Limitations

V21's predictions are estimates and its spatial memory is coarse. It cannot infer unseen Minecraft state with certainty. Exploration is bounded and conservative, and actual gameplay quality still depends on perception, models, latency and environment.
